# Student Profile and Skill Development Management System

**Subject:** OOPJ (CS336B)  
**Question:** Q1(a)  
**Language:** Java 21  
**Build Tool:** Maven  
**IDE:** IntelliJ IDEA

## Project Description

This project implements a Student class for managing student profile information and technical skills using Java Object-Oriented Programming concepts.

## Features

- Student ID, name, email and course details
- Programming and Mathematics scores
- Technical skills using Java List
- Encapsulation using private data members
- Default and parameterized constructors
- Getters and setters
- Skill addition method
- Object representation using toString()

## Project Structure

```text
src/main/java/com/studentmanagement/
├── Main.java
└── model/
    └── Student.java
```

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Reload the Maven project.
4. Run `Main.java`.

## Output

The program creates a student profile, updates the programming score and adds a technical skill.
